# 用户注册 + 记住密码 + 修改密码 + 审批流程 实现计划

## 1. User 类型增加 status 字段

**文件**: `src/types/index.ts`

在 User 接口中增加 `status: 'active' | 'pending' | 'disabled'` 字段。现有用户默认 `active`。

## 2. useUserStore 增加注册、审批、修改密码方法

**文件**: `src/stores/useUserStore.ts`

### 2a. 数据库迁移
- `initUsersTable()` 中 ALTER TABLE 增加 `status` 列（默认 `'active'`）
- 现有用户全部设为 `active`

### 2b. 新增方法
- `registerUser(username, password)` — 创建 status=pending 的用户，返回成功/失败（用户名重复检查）
- `approveUser(userId, roleIds)` — 将 status 从 pending 改为 active，分配角色
- `rejectUser(userId)` — 删除待审批用户（或标记为 rejected）
- `changePassword(userId, oldPassword, newPassword)` — 验证旧密码后更新密码哈希

## 3. useAuthStore 登录逻辑调整

**文件**: `src/stores/useAuthStore.ts`

- 登录时检查 `status === 'pending'`，提示"账号待审批，请联系管理员"
- 登录时检查 `status === 'disabled'`，提示"账号已禁用"
- 增加 `rememberMe` 参数，登录成功后根据开关决定是否保存用户名+密码到 localStorage
- 页面加载时从 localStorage 读取记住的凭据

## 4. 登录页改造

**文件**: `src/app/login/page.tsx`

### 4a. 记住密码
- 增加"记住密码"复选框（默认不勾选）
- 页面加载时从 localStorage 读取 `saved_credentials`，自动填充用户名和密码
- 登录成功后根据勾选状态保存/清除凭据

### 4b. 注册表单
- 登录表单下方增加"注册账号"链接
- 点击后切换到注册表单（用户名、密码、确认密码）
- 注册成功后提示"注册成功，请等待管理员审批"，自动切回登录表单
- 注册表单下方有"返回登录"链接

## 5. 用户管理页增加审批功能

**文件**: `src/app/settings/users/page.tsx`

- 用户列表增加"状态"列（待审批=黄色Badge、正常=绿色、已禁用=红色）
- 待审批用户行增加"审批"和"拒绝"按钮
- 点击"审批"弹出对话框：选择角色 → 确认 → 状态变为 active
- 点击"拒绝"确认后删除该用户

## 6. 修改密码功能

**文件**: 新建 `src/components/shared/change-password-dialog.tsx`

### 6a. 对话框组件
- 三个输入框：旧密码、新密码、确认新密码
- 验证：旧密码正确、新密码长度≥6、两次新密码一致
- 调用 `useUserStore.changePassword()`

### 6b. 入口
- **文件**: `src/components/layout/sidebar.tsx`
- 侧边栏底部用户区域增加下拉菜单（用户名 + 头像/图标）
- 下拉菜单项：修改密码、退出登录
- 点击"修改密码"打开 ChangePasswordDialog
