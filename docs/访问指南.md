# 项目管理系统访问指南

## 📋 项目管理系统位置

这个项目管理系统是一个独立的Web应用，与Claude Team无关。

### 🌐 访问地址

- **项目管理中心**：http://localhost:3001/project
- **应用首页**：http://localhost:3001

## 🔧 启动步骤

1. **打开命令提示符**
2. **进入项目目录**：
   ```
   cd D:\AI\ai-finance-assistant
   ```
3. **启动开发服务器**：
   ```
   npm run dev
   ```
4. **等待启动完成**，看到类似这样的输出：
   ```
   ✓ Starting...
   ✓ Ready in 7.5s
   - Local: http://localhost:3001
   ```

## 🚀 如何使用

### 1. 访问项目管理中心

- 在浏览器中打开：http://localhost:3001/project
- 或先访问首页，然后点击左侧边栏的"项目管理"

### 2. 功能模块

项目管理中心包含以下功能：

- **📊 统计仪表板**：显示项目各项指标
- **📋 看板视图**：拖拽式任务管理
- **📄 文档管理**：文档上传和管理
- **🎯 里程碑**：项目进度跟踪
- **🔄 需求变更**：变更申请和处理

### 3. 快速上手

1. **创建任务**：点击"新建任务"，填写任务信息
2. **管理文档**：上传技术文档、测试文档等
3. **跟踪进度**：使用看板拖拽更新任务状态
4. **记录变更**：通过需求变更模块提交新需求

## ❓ 常见问题

### Q: 为什么打不开？
A:
1. 确保开发服务器已启动
2. 检查是否输入正确地址：http://localhost:3001
3. 确认端口3001没有被占用

### Q: 数据会保存吗？
A: 是的，所有数据都保存在浏览器本地，刷新页面不会丢失。

### Q: 与Claude Team的关系？
A: 这是完全独立的本地应用，专门用于软件开发项目管理，与Claude Team无关。

## 📞 支持

如果遇到问题，请检查：
1. Node.js版本是否为18+
2. 是否已安装所有依赖（npm install）
3. 浏览器控制台是否有错误信息
