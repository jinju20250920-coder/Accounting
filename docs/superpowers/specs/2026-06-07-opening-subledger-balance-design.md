# Opening Subledger Balance Design

期初初始化采用“子账明细为来源，总账余额为结果”的口径。

## Scope

- 科目余额页仍负责总账借贷平衡。
- 银行、客户、供应商、固定资产作为子账明细来源。
- 子账明细汇总与总账科目不一致时，只提示差异，不自动用会计科目补子账。
- 总账借贷不平时，允许用户显式选择一个期初平衡调整科目补平。

## Rules

- 银行期初明细汇总到 `1002 银行存款`。
- 客户期初应收汇总到 `1122 应收账款`。
- 供应商期初应付汇总到 `2202 应付账款`。
- 固定资产原值汇总到 `1601 固定资产`。
- 固定资产累计折旧汇总到 `1602 累计折旧`。
- 补平科目只能处理总账借贷差额，不能掩盖子账明细差异。

## Save Behavior

- 总账平衡且子账一致：允许保存并生成期初凭证。
- 总账不平但选择了补平科目：生成一条期初平衡调整分录后允许保存。
- 子账与总账不一致：允许暂存期初凭证，但页面必须展示未分配差异。
