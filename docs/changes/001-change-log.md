## v1.0.3 (2026-03-15)

### ✨ 新增功能

#### 凭证批量打印功能
- **按月筛选**：支持选择特定月份的凭证进行批量打印
- **单据编号筛选**：通过搜索功能筛选特定单据编号的凭证
- **标准记账凭证格式**：实现符合财务规范的记账凭证打印格式
- **批量打印选择**：支持选择多个凭证进行打印，每张凭证单独分页

#### 打印功能特点
- **标准格式**：
  - 单位名称和日期显示
  - 凭证号和摘要信息
  - 科目借贷方金额
  - 中文大写金额转换
  - 制单人、审核人等签字栏

- **分页处理**：每张凭证单独分页，确保打印格式美观
- **打印预览**：点击打印前可预览所有要打印的凭证
- **灵活选择**：支持单选、多选和全选

### 📋 变更影响

- **新增页面组件**：`PrintableVoucher`组件负责处理凭证打印格式
- **新增打印样式**：添加了专门的打印CSS样式
- **数字转换功能**：实现了数字金额到中文大写金额的转换
- **凭证格式化**：确保每张凭证打印时的格式一致性

### 🔧 技术实现

- **打印样式优化**：使用`@media print`实现打印与屏幕显示的样式分离
- **分页控制**：使用`page-break-after`属性控制每张凭证单独分页
- **中文金额转换**：实现了完整的财务数字到中文大写的转换逻辑
- **数据填充**：确保每张凭证至少有6行分录，符合财务凭证规范

getSmartMatch() {
  // L1: 关键词规则匹配
  const ruleMatches = rules.filter(rule => summary.includes(rule.keyword));

  // L2: 用户偏好匹配
  const userMatches = userPrefs.filter(pref =>
    summary.includes(pref.summary) || pref.summary.includes(summary)
  );

  // 返回置信度最高的匹配
  return mergeResults([...userMatches, ...ruleMatches]);
}
